# Wrap-up

## Key takeaways

- Cilium uses eBPF to provide networking and security capabilities, with Hubble for flow visibility.
- On AKS, Azure CNI powered by Cilium provides a managed implementation with its own supported capabilities and constraints.
- Ingress and egress policies help isolate workloads; observability helps validate and troubleshoot their traffic.
